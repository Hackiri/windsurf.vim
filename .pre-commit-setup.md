# Pre-commit Setup for windsurf.nvim

This project uses pre-commit hooks to ensure code quality and consistency.

## Installation

1. Install pre-commit:

```bash
pip install pre-commit
```

2. Install the git hook scripts:

```bash
pre-commit install
```

3. Install required tools:

```bash
# Install StyLua for Lua formatting
cargo install stylua

# Install luacheck for Lua linting
luarocks install luacheck

# Install prettier for markdown/json formatting
npm install -g prettier
```

## Usage

Pre-commit will automatically run when you commit. To run manually:

```bash
# Run on all files
pre-commit run --all-files

# Run on staged files only
pre-commit run
```

## Configuration Files

- `.pre-commit-config.yaml` - Main pre-commit configuration
- `.stylua.toml` - StyLua formatting configuration
- `.luacheckrc` - Luacheck linting configuration

## Hooks Included

- **check-yaml** - Validates YAML files
- **end-of-file-fixer** - Ensures files end with newline
- **trailing-whitespace** - Removes trailing whitespace
- **stylua** - Lua code formatting
- **luacheck** - Lua code linting
- **prettier** - Markdown/JSON formatting
